# Script and storyboard: Door codes for every guest, assigned and revoked automatically

This is the on-screen script for the 10 second loop. The music version plays the same loop twice (20 seconds) with a music track. There is no voiceover and no caption line.

All names, dates, and door codes are sample data.

## Headline

> Door codes for every guest, assigned and revoked automatically

## Numbered steps

1. A guest books, and the system assigns them a code
2. They get their door code in the welcome message, a week before, and a day before their stay
3. Every guest and contractor has their own code, so you know who's coming and going
4. The code is automatically revoked after checkout and never reused

The steps are shown as approved. The highlight on the steps moves in sync with the demo.
